# ループBGMメーカー / Loop BGM Maker

テーマと曲調を選ぶと、ループ再生できるBGMを「譜面データ（JSON）」として設計し、プログラムが音にするための**指示書（仕様書）と参照実装**を公開するプロジェクトです。

音声を一発生成する方式ではなく、パート（メロディ／ベース／コード／ドラム）ごとに分かれた譜面を作るため、後から「ベースだけ直す」「テンポだけ変える」ができます。ループの継ぎ目が汚くならないよう、尺と継ぎ目を機械検証する仕組みまで含めて1セットにしています。

## 使い方（2通り）

1. **すぐ試す**: `reference/index.html` をブラウザで開くだけで、生成・ループ試聴・WAV／MIDI／譜面JSON書き出し・検証表示が使えます（外部素材なし、入力や生成物は外部送信されません）。

生成の仕組み：参照実装の作曲はプログラムによる自動作曲で、LLMは不要です（テーマの言葉は乱数の種の材料になります。情景まで汲んだ作曲をしたい場合は、指示書をAIに読ませる経路を使ってください）。生成のたびにランダムな種（シード）を引き、種は譜面データに記録されます。同じテーマ・設定・種を指定すれば同じ曲を再現でき、種が違えば他の人と曲が被りません。
2. **自分のAIエージェントに作らせる**: `docs/instruction.md`（指示書）を Claude / Muse 等に読ませると、同等のメーカーを自分の環境に作れます。指示書には作り方だけでなく、検証（テスト）と法的整備の決まりも含まれます。

## モード（4種）

| モード | 内容 |
|---|---|
| スタンダード | メロディ＋コード＋ベース＋ドラムの汎用編成（全合成・固定楽器） |
| レトロ4ch | パルス波×2＋波形メモリ＋ノイズの4チャンネル構成。拡張1「三角波ベース」、拡張2「サンプルドラム」で5ch構成にも |
| ピアノソロ | ピアノ1パートのみ |
| アンビエント | パッド＋まばらな音の環境音楽 |

曲調プリセット（テイスト）は12種：ポップ／ほのぼの日常／落ち着いた（lofi）／バラード／和風／ジャズ風／ロック／エレクトロニック／戦闘／神秘的／ダーク／ホラー／壮大／冒険。

効果音（決定・成功・ジャンプ等8カテゴリ、全合成）は分離可能なモジュールとして同梱しています。

## 検証

参照実装には自動テストが同梱されています。

```sh
cd reference
node tests.mjs   # 譜面生成・モード制約・MIDI構造などを検証
```

ブラウザ上では、全モード構成×全テイストを実際にレンダリングして尺・継ぎ目・無音/音割れを照合する「一括検証」も実行できます。
