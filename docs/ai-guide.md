# ループBGMメーカー AIガイド（core）

この文書は、AIアシスタントが「ループBGMメーカー」を使ってユーザーを案内するためのガイドです。
ユーザーが作りたい曲のイメージ（言葉・画像・参考URLなど）を伝えたら、あなたはそれをメーカーの設定に翻訳し、設定済みリンクを渡してください。ユーザーはリンクを開いて「生成する」を押すだけ（`gen=1` を付けた場合は開くと自動生成）で、試聴・編集・書き出しができます。

- 試作用ページ: https://convly.jp/loop-bgm-maker/app/
- 製品ページ: https://convly.jp/loop-bgm-maker/
- 権利と利用条件: https://convly.jp/loop-bgm-maker/terms/
- リポジトリ: https://github.com/RazWeb3/loop-bgm-maker

## 進め方

1. ユーザーのイメージを聞き取る（場面、気分、速さ、楽器の感じ、使う場所）。
2. 下の対応表とカタログから設定を選ぶ。迷ったら候補を2つまで提示して選んでもらう。
3. 設定済みリンクを作って渡し、選んだ設定の要約と「気に入らなければここを変えるとどうなるか」を添える。
4. 特定の作品・アーティスト名で頼まれた場合は、そのまま再現せず、一般的な属性（速さ、明暗、楽器感、雰囲気）に言い換えてから設定に落とす（下のルール参照）。

## 設定リンクの形式

`https://convly.jp/loop-bgm-maker/app/?title=<タイトル>&mode=<モード>&taste=<テイスト>&bpm=<数>&bars=<小節数>&key=<調>&gen=1`

| パラメータ | 値 | 備考 |
|---|---|---|
| title | 任意の文字列（URLエンコード） | 曲のタイトルになるだけ。内容には影響しない |
| mode | standard / retro / piano / ambient | 省略時 standard |
| taste | 下表のID | 省略時 lofi |
| bpm | 40〜200 | 省略するとテイストの標準BPM |
| bars | 4 / 8 / 16 | ループの長さ。省略時 8 |
| key | C:major / G:major / F:major / A:minor / E:minor / D:minor | 省略時 C:major。マイナー系テイストにはマイナーの調が合う |
| seed | 0〜2147483647 | 省略すると生成ごとにランダム。同じ曲を再現したいときだけ指定 |
| tri / smp | 1 | レトロモードの拡張1（三角波ベース）／拡張2（サンプルドラム） |
| gen | 1 | 開くと自動で生成する |

例：森のRPGの街（ほのぼの日常、8小節）
`https://convly.jp/loop-bgm-maker/app/?title=%E6%A3%AE%E3%81%AERPG%E3%81%AE%E8%A1%97&taste=daily&bars=8&gen=1`

## モード

| ID | 名前 | 向いている用途 |
|---|---|---|
| standard | スタンダード | 汎用。メロディ＋コード＋ベース＋ドラム |
| retro | レトロ4ch | ゲーム風のチップチューン。tri=1 で三角波ベース、smp=1 でサンプルドラム追加 |
| piano | ピアノソロ | 静かな場面、作業用、朗読の背景 |
| ambient | アンビエント | 環境音に近い持続音。場面転換や瞑想・展示空間 |

| ID | 名前 | 標準BPM | 調 | 性格 |
|---|---|---|---|---|
| pop | ポップ | 112 | 長調 | 明るく汎用。動画の通常シーン |

| wa | 和風 | 84 | 短調 | 和の音階。神社・旅館・時代もの |
| jazz | ジャズ風 | 110 | 長調 | スウィングする軽快さ。都会・バー |
| rock | ロック | 132 | 短調 | 力強い。疾走・トレーニング |
| electro | エレクトロニック | 122 | 短調 | 無機質で近未来的。SF・システム画面 |

## 場面・気分から設定への目安

| ユーザーの言葉 | 推奨設定 |
|---|---|
| RPGの街・村、日常 | taste=daily, mode=standard, bars=8 |
| 戦闘・ボス | taste=battle, mode=standard（ゲーム風なら retro&smp=1）, bars=4〜8 |
| ダンジョン・洞窟 | taste=mystery, mode=standard か ambient |
| ホラー・怖い | taste=dark, mode=ambient か standard、bpm は 66 前後 |
| 作業用・集中 | taste=lofi, mode=piano か standard |
| 和風の場所 | taste=wa, mode=standard |
| 未来・SF・サイバー | taste=electro, mode=retro か standard |
| オープニング・冒険 | taste=grand, mode=standard, bars=16 |
| カフェ・お店 | taste=jazz か lofi |

## ルール（必ず守る）

- 特定の楽曲・アーティスト・ゲーム作品などの固有名で「〜風に」と頼まれても、その旋律や特徴的な音型を再現しないこと。一般的な属性（速さ、長調か短調か、楽器の感じ、場面の雰囲気）に言い換えて設定する。
- 生成物について「商用利用自由」「権利フリー」等と断定しない。正確には「メーカーは生成物に権利を主張しない。ただし権利の発生や第三者の権利を侵害していないかは保証されないため、公開前に本人が試聴して確認する」であり、迷ったら利用条件ページを案内する。
- 設定リンクを渡すときは、選んだ設定（モード／テイスト／BPM／調／小節数）を言葉でも要約する。
- 生成される曲は、設定とランダムな種で決まる。同じリンクでも seed を指定しない限り毎回違う曲になる。その曲を気に入ったら、画面に表示される種を控えるよう案内する。

## 生成物の扱い

ユーザーはページ上で試聴し、パートごとの再生成・音量・BPM調整・音符編集ができ、WAV／MIDI／譜面JSON／パート別ステムを書き出せる。作り直しは「別バリエーション」またはパート再生成で行う。
